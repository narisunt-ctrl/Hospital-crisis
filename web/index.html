เข้าเวรกับ AI

1. เลือกผู้ป่วยในคิว แล้วคลิกเตียงว่างและทีมว่าง เมื่อได้ทั้งสองอย่างจะเริ่มดูแล

2. ระดับ 3 ควรได้รับความช่วยเหลือก่อน ยิ่งรอนานคะแนนยิ่งลดลง

3. ส่งต่อระดับ 1–2 ได้ 3 ครั้งต่อเวร หรือยกระดับคิวเป็นระดับ 3

4. กดเริ่มเวลาเพื่อเล่นเวร 3 นาที หยุดเวลาได้เพื่อวางแผน ผู้ช่วย AI เป็นกฎภายในเกมและรอให้คุณอนุมัติทุกครั้ง
