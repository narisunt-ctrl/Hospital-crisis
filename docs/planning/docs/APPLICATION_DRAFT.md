**Hospital Crisis: Self-Evolving Emergency Room**  
Thai: **โรงพยาบาลวิกฤต: เข้าเวรกับ AI**

## One-line pitch
A playable emergency-room simulator where Codex autonomously improves an AI resource-allocation strategy, then proves the upgrade with reproducible safety-gated benchmarks.

## Project idea — English (ready to adapt)
We propose **Hospital Crisis**, a browser-based emergency-room strategy game where a human player cooperates with an AI agent to triage a queue of simulated patients and allocate scarce staff and beds during sudden surges. The key innovation is not an AI chatbot: **OpenAI Codex acts as a software-engineering agent** that reviews the outcome of a round, edits a strategy plugin, and tests the new implementation against repeatable scenarios. A protected evaluator compares the old and new versions and promotes an update only if it improves performance without violating safety constraints. The game will visualize the code diff, test results, and the impact of the evolved strategy. We will prioritize a compact, working vertical slice within the hackathon's one-day build window, using synthetic data only. The concept aligns with **Autonomous & Adaptive AI** and **Deep Domain AI** by connecting autonomous coding agents with measurable operational decisions in a healthcare-inspired simulation.

## Why this is distinctive
- Measurable improvement is demonstrated with controlled benchmarks, **not** claimed from superficial prompts.
- Codex edits a strategy implementation; the game shows code changes and their consequences.
- Safety gates and fallback show trustworthy autonomy rather than uncontrolled self-modification.
- Domain-rich operational simulation without accessing real patient data or providing medical treatment advice.
